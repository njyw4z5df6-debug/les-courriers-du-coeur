# Les Courriers du Cœur

Une première page d’accueil douce et responsive pour un futur espace d’écoute et de correspondance bienveillante.

## Voir le site sur son ordinateur

1. Installer [Node.js](https://nodejs.org/) (version 20 ou plus récente).
2. Ouvrir un terminal dans ce dossier.
3. Lancer `npm install` une seule fois.
4. Lancer `npm run dev`.
5. Ouvrir l’adresse affichée dans le terminal (généralement `http://localhost:5173`).

## Commandes utiles

- `npm run dev` : démarre le site en mode aperçu.
- `npm run build` : vérifie et prépare une version publiable.
- `npm run lint` : vérifie la qualité du code.

## Structure

- `src/pages` : les pages du site.
- `src/components` : les éléments réutilisables (menu, pied de page, etc.).
- `src/data` : les contenus faciles à faire évoluer, notamment les catégories.
- `src/styles` : l’identité visuelle et l’adaptation aux écrans.

Les paiements, les comptes et la messagerie ne sont volontairement pas activés à cette étape.
